# OpenGL 실습 4 — 사각형 애니메이션

## 기본
- 배경은 어두운 회색.
- 사각형은 임의의 색상.
- 마우스 클릭 위치가 사각형의 중심.
- 최대 5개.
- 5개 이후 추가 입력 불가.

## 키보드
### 1 — Position Change 1
- 사각형이 대각선으로 이동.
- 벽에 부딪히면 튕겨 다른 방향으로 이동.
- 화면 밖으로 나가지 않도록 경계 처리.

### 2 — Position Change 2
- 사각형이 수평 방향으로 지그재그 이동.
- 경계에 도달했을 때 방향을 바꾸는 방식으로 구현.
- 화면 밖으로 나가지 않도록 처리.

### 3 — Position Change 3
- 모든 사각형이 윈도우 가장자리를 따라 이동.
- 시계 방향으로 순서대로 이동.
- 위 → 오른쪽 → 아래 → 왼쪽 가장자리 경로를 사용.
- 여러 사각형의 이동 순서가 보이도록 구현.

### 4 — Size Change
- 사각형이 반복해서 커졌다 작아진다.
- 최소/최대 크기를 정해 범위를 벗어나지 않게 한다.
- 중심 위치는 유지한다.

### 5 — Color Change
- 사각형의 색상을 임의의 색상으로 계속 변경한다.

### s — Stop
- 모든 애니메이션 정지.
- 사각형은 삭제하지 않는다.
- 현재 위치/크기/색상을 유지한다.

### m — Move
- 모든 사각형을 처음 그려졌던 위치로 되돌린다.
- 사각형 개수는 유지한다.

### r — Reset
- 사각형을 모두 삭제한다.
- 다시 마우스로 생성할 수 있게 한다.
- 애니메이션 상태도 초기화한다.

### q — Quit
- 프로그램 종료.

## 키 상호작용 정리
- 1~3: 위치 애니메이션 방식 선택/실행.
- 4: 크기 애니메이션.
- 5: 색상 애니메이션.
- s: 모든 애니메이션 정지.
- m: 최초 위치 복원.
- r: 전체 삭제 후 재입력.
- q: 종료.
- 여러 애니메이션의 상태가 충돌하지 않도록 상태 변수를 설계한다.

## 구현 상태
- 현재/최초 위치
- 크기
- 색상
- 이동 방향과 속도
- 크기 변화 방향과 속도
- 애니메이션 실행 상태
- 현재 이동 모드
- 색상 변경 상태

## 입력 처리
- 키보드는 Key Callback.
- 마우스 버튼은 Mouse Button Callback.
- 연속 애니메이션은 매 프레임 상태를 갱신.
- 기존 실습의 좌표 변환, 사각형 자료구조, 랜덤 색상 코드를 재사용 가능.

## 원문에서 별도로 정하지 않은 구현 세부
- 1~3의 정확한 속도값.
- 2의 정확한 지그재그 경로/주기.
- 3에서 사각형 사이의 간격과 출발점.
- 4의 최소/최대 크기와 변화 속도.
- 5의 색상 변경 주기.
이 값들은 과제의 동작을 만족하도록 구현 단계에서 정한다.
