# Practice 14 — 꼭짓점 색상을 이용한 3차원 객체 그리기

자료 근거: 「지엘3 좌표계 변환 (실습 131415).pdf」 실습 14 슬라이드.

## 1. 과제 텍스트 전문 추출 (OCR)

**실습 14**
- 꼭지점을 이용하여 3차원 객체 그리기
- 화면 중앙에 화면 좌표계 (x, y, z축)을 그린다. 좌표계는 이동하지 않고 고정되어 있다.
- 키보드 명령에 따라 육면체 혹은 사각뿔을 그린다. 각 꼭지점에 다른 색상 설정한다.
- 객체는 x축으로 30도, y축으로 30도 회전해 있다. (회전 각도는 변경 가능)
- 키보드 명령:
  - c: 육면체
  - p: 사각 뿔 (피라미드 모양으로 바닥은 사각형, 옆면은 삼각형)
  - h: 은면제거 적용/해제
  - w/W: 와이어 객체/솔리드 객체
  - x/X: x축을 기준으로 양/음 방향으로 회전 애니메이션 (자전)
  - y/Y: y축을 기준으로 양/음 방향으로 회전 애니메이션 (자전)
  - ←/→/↑/↓: 좌/우/상/하로 객체를 이동한다. (x축, y축으로 이동)
  - s: 초기 위치로 리셋 (모든 애니메이션 멈추기)

## 2. 그래픽스 기본 환경 분석

과제 내용상 OpenGL 기반 3D 렌더링으로 해석한다. 창 라이브러리, 창 크기, 배경 RGB, 투영 방식은 원문에 없다. 기존 프로젝트 설정을 유지한다. 정점마다 색상이 다르므로 정점 위치와 색상 데이터를 함께 전달해야 한다.

모든 정점은 x/y/z 3D 좌표를 갖는다. 화면 중앙 좌표축은 고정되어야 한다. 객체 이동/회전 시 축까지 변하면 안 되므로 축과 객체에 별도의 변환을 적용한다. 객체 초기 기울기는 x축 30도, y축 30도이며 변경 가능하다.

각 꼭짓점은 서로 다른 색을 가진다. 정점 색상을 삼각형 내부에서 보간하면 면 안에서 색이 부드럽게 섞인다. 원문은 정확한 RGB 값을 정하지 않는다. w/W는 와이어 객체/솔리드 객체 전환이다. 어느 대소문자가 어느 모드인지는 원문에 더 구체적으로 적혀 있지 않으므로 w=wireframe, W=solid 등으로 규칙을 정해 일관되게 구현한다.

## 3. 키보드 상호작용 및 내부 상태

| 입력 | 동작 | 상태 |
|---|---|---|
| c | 육면체 | 현재 객체 종류 Cube |
| p | 사각뿔 | 현재 객체 종류 Pyramid |
| h | 은면 제거 설정/해제 | 깊이 테스트 bool 반전 |
| w/W | 와이어/솔리드 | 렌더 모드 변경 |
| x/X | x축 양/음 방향 회전 애니메이션 | 회전 속도/방향 갱신 |
| y/Y | y축 양/음 방향 회전 애니메이션 | 회전 속도/방향 갱신 |
| 방향키 | x/y 방향 이동 | 위치 상태 변경 |
| s | 초기 위치, 모든 애니메이션 리셋 | 위치/회전/속도 초기화 |

필요한 상태는 현재 도형 종류, 깊이 테스트 활성 여부, 렌더 모드, x/y 회전각, 회전 속도 또는 방향, x/y 위치, 초기 위치와 초기 회전값이다. 원문은 회전 키가 토글인지 계속 회전 상태를 지정하는지 정하지 않는다. s는 모든 애니메이션을 멈춰야 하므로 각도뿐 아니라 회전 속도와 활성 상태도 초기화한다.

## 4. 단계별 코딩 구현 계획

1. 육면체 8개 정점, 사각뿔 바닥 4개 정점과 꼭짓점 1개를 정의한다.
2. 각 정점에 RGB를 지정하고 위치 배열과 색상 배열의 순서가 일치하는지 확인한다.
3. 면을 구성하는 정점 인덱스를 정의한다. 사각형 면을 삼각형으로 렌더링한다면 삼각형 두 개로 나눈다.
4. c로 육면체, p로 사각뿔을 표시하고 초기 x/y 30도 회전을 적용한다.
5. 좌표축을 고정 좌표계로 먼저 그린 뒤 객체에만 model transform을 적용한다.
6. h 입력으로 깊이 테스트를 토글하고 매 프레임 깊이 버퍼를 초기화한다.
7. w/W 입력으로 와이어와 솔리드 모드를 전환한다. 필요한 경우 렌더링 상태를 원래 값으로 복구한다.
8. x/X, y/Y로 회전 방향을 설정한다. 애니메이션은 delta time을 이용해 FPS와 무관한 속도로 갱신한다.
9. 방향키로 객체의 x/y 위치를 바꾸되 좌표축은 움직이지 않게 한다.
10. s 입력 시 위치, 초기 기울기, 회전각, 회전 속도와 애니메이션 상태를 모두 초기화한다.
11. 모든 키 기능을 독립적으로 테스트한다.

- [ ] 객체는 x/y축 기준 30도 기울어져 있다.
- [ ] 좌표축은 객체 변환과 무관하게 고정되어 있다.
- [ ] h로 은면 제거를 켜고 끈다.
- [ ] w/W로 와이어/솔리드 모드를 바꾼다.
- [ ] x/X와 y/Y는 반대 방향 회전을 한다.
- [ ] 방향키는 객체만 이동시킨다.
- [ ] s는 모든 애니메이션을 멈추고 초기 상태로 돌아간다.

## 6. 오류 해결과 미확정 사항

한 색만 보이면 정점 색상 데이터의 인덱스/stride/offset 또는 셰이더 전달을 확인한다. 축이 움직이면 축과 객체가 같은 model matrix를 쓰는지 확인한다. 속도가 FPS에 따라 다르면 delta time을 사용한다. 리셋 후에도 회전하면 속도와 활성 상태까지 초기화한다.

창 크기, 배경색, 정확한 색상, 이동 단위, 회전 속도, w/W의 대소문자별 매핑, 투영 방식은 원문에 없다. 선택한 규칙을 문서화한다.
