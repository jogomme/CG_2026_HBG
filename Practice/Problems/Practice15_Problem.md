# Practice 15 — 육면체와 사각뿔의 면 애니메이션

자료 근거: 「지엘3 좌표계 변환 (실습 131415).pdf」 실습 15 슬라이드.

## 1. 과제 텍스트 전문 추출 (OCR)

**실습 15**
- 육면체와 사각뿔 애니메이션
- 육면체와 사각뿔은 각 면에 다른 색을 배정한다.
- 두 객체는 초기에 X축과 y축으로 약간 기울어져 있다.
- 키보드 명령:
  - h: 은면 제거 설정/해제
  - p: 육면체/사각뿔
  - y: y축에 대하여 자전한다/멈춘다.
  - r: 리셋하고 육면체 출력
  - q: 프로그램 종료

**육면체 한 면 애니메이션**
- t: 윗면의 가운데 축 (z축)을 중심으로 회전/멈추기
- f: 앞면이 위축을 기준으로 회전하여 열기/닫기
- s: 옆면이 중점을 기준으로 제자리에서 회전/멈추기
- b: 뒷면이 제 자리에서 작아지면서 없어진다/다시 커지면서 원래 크기가 된다.

**육면체 두 면 애니메이션**
- 1: 옆면 4개에서 같은 모서리를 사용하는 두 면 중 랜덤하게 선택하여 모서리를 기준으로 (y축) 360 회전한다.
- 2: 같은 모서리를 사용하는 두 면 중 랜덤하게 선택하고, 두 면이 육면체 중앙의 y축을 기준으로 서로 반대방향으로 90도 공전하여 자리를 교체한다.

**육면체 네 면 애니메이션**
- 4: 육면체의 4개의 옆면이 육면체 중앙의 y축을 기준으로 공전한다.
- 5: 육면체의 윗면, 아랫면, 2개의 옆면에 육면체 중앙의 x축을 기준으로 공전한다.

## 2. 그래픽스 기본 환경 분석

내용상 OpenGL 3D 그래픽스 과제다. 창 크기, 배경색, 카메라, 투영 방식, 속도는 원문에 없다. 육면체는 면 6개, 사각뿔은 사각형 바닥 1개와 삼각형 옆면 4개로 구성한다. 면마다 다른 고정 색상을 부여한다. 초기 기울기는 x/y축 기준으로 약간 기울어진 상태지만 정확한 각도는 지정되지 않았다.

자전은 객체 또는 면이 자기 축/중심을 기준으로 회전하는 것이고, 힌지 회전은 공유 모서리를 축으로 여는 것이며, 공전은 육면체 중앙의 외부 축 주위를 돌면서 위치를 바꾸는 것이다. 뒷면 축소는 면 중심을 유지하며 크기를 줄이는 스케일 변환이다.

## 3. 키보드 상호작용 및 상태 설계

### 전체 명령
| 키 | 동작 |
|---|---|
| h | 은면 제거 켜기/끄기 |
| p | 육면체/사각뿔 전환 |
| y | y축 자전/멈춤 |
| r | 리셋하고 육면체 출력 |
| q | 프로그램 종료 |

### 한 면 애니메이션
- t: 윗면을 가운데 축(z축) 기준으로 회전/멈춘다.
- f: 앞면이 “위축” 기준으로 회전하여 열린다/닫힌다. 원문 표현만으로 축을 확정하기 어렵기 때문에 수업에서 정의한 앞면과 축을 확인하고 주석으로 기록한다.
- s: 옆면을 면의 중점 기준으로 제자리 회전/멈춘다.
- b: 뒷면이 제자리에서 작아져 사라지고, 다시 커져 원래 크기가 된다.

### 두 면 애니메이션
- 1: 옆면 4개 중 같은 모서리를 공유하는 두 면을 랜덤 선택하고 공유 모서리 기준으로 360도 회전한다.
- 2: 같은 모서리를 공유하는 두 면을 랜덤 선택하고 육면체 중앙 y축 기준으로 서로 반대 방향으로 90도 공전시켜 자리를 교체한다.
- 랜덤 면 쌍은 애니메이션 시작 시 한 번만 선택한다. 두 면은 실제로 인접해 공유 모서리를 가져야 한다.

### 네 면 애니메이션
- 4: 옆면 4개가 육면체 중앙 y축 기준으로 공전한다.
- 5: 윗면, 아랫면, 옆면 두 개가 육면체 중앙 x축 기준으로 공전한다.
- 원문은 5에서 사용할 옆면 두 개의 조합을 지정하지 않는다. 구현에서 면 조합을 정하고 기록한다.

필요한 상태는 현재 도형, 깊이 테스트 상태, 전체 y축 자전 상태/각도, 각 애니메이션의 활성 상태와 각도/진행값, 랜덤 선택된 면 인덱스, 뒷면 scale이다. 원문은 애니메이션 동시 실행 규칙을 정하지 않는다. 첫 구현에서는 새 면 애니메이션이 시작되면 기존 면 애니메이션을 멈추도록 하면 관리가 쉽다.

## 4. 변환 원리

### 힌지 회전
면을 공유 모서리 기준으로 돌리려면 그 모서리를 피벗으로 삼는다. 개념적 순서는 피벗을 원점으로 이동 → 회전 → 원래 위치로 이동이다. column-vector convention의 행렬 표기는 T(pivot) * R(axis, angle) * T(-pivot)이다. 사용하는 수학 라이브러리의 행렬 곱 convention을 확인한다.

### 면 중심 회전
면 중심을 피벗으로 회전하면 중심 위치는 유지되고 면의 방향만 변한다.

### 중앙축 공전
육면체 중앙의 x/y축을 기준으로 공전하면 면의 위치가 중심축 주위를 이동한다. 면 중심 회전과 구분해야 한다.

### 스케일
뒷면을 제자리에서 축소하려면 면 중심 기준 scale을 사용한다. scale을 1에서 0으로 줄이고 다시 1로 키운다. 원본 정점은 보존하고 현재 각도/scale만 변환에 반영하면 원래 형태로 돌아오기 쉽다.

## 5. 단계별 코딩 구현 계획

1. 육면체의 8개 정점과 6개 면을 정의하고 면마다 고정 색을 부여한다.
2. 윗면/앞면/뒷면/옆면에 이름과 인덱스를 부여한다.
3. 전체 객체 렌더링과 면 하나 렌더링을 분리한다.
4. h/p/y/r/q를 먼저 구현한다. r은 육면체로 돌아가고 모든 애니메이션을 멈춘다.
5. 프레임 시간 차이를 이용해 각도와 scale을 갱신한다.
6. t는 윗면 중심축 회전, f는 앞면 힌지 회전, s는 옆면 중심 회전, b는 뒷면 scale 애니메이션으로 구현한다.
7. 인접한 옆면 쌍 목록을 만든다. 1/2 입력 시 쌍 하나를 무작위로 선택한다.
8. 1은 공유 모서리 기준 360도 회전, 2는 중앙 y축 기준 반대 방향 90도 공전을 구현한다.
9. 4는 옆면 4개를 중앙 y축 기준으로 공전시킨다.
10. 5는 윗면/아랫면/옆면 2개를 중앙 x축 기준으로 공전시킨다.
11. r에서 각도, scale, 선택 면, 애니메이션 활성 상태와 속도를 초기화한다.

## 7. 오류 해결과 미확정 사항

면이 원점 주위로 돌면 피벗 이동을 확인한다. 회전 중 면이 튀면 pivot/축과 행렬 곱 순서를 확인한다. 랜덤 선택이 계속 바뀌면 키 입력 때 한 번만 선택한다. 리셋 후에도 움직이면 활성 상태와 속도까지 초기화한다. FPS에 따라 속도가 달라지면 delta time을 사용한다.

초기 기울기의 정확한 각도, 회전 속도, 열기/닫기 방식, f의 정확한 회전축, 5에서 선택할 옆면 조합, 동시 실행 규칙, 창 크기와 색상은 원문에서 정하지 않는다.
