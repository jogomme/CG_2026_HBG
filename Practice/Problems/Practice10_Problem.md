# Practice 10 — 작은 도형으로 새로운 모양 만들기

## 1. 실습 목표

작은 기본 도형들을 마우스로 선택하고 드래그하여 오른쪽의 모양판에 정확하게 배치한다.

작은 도형들이 정해진 모양판 위에 모두 올라가면 그 모양은 완성된 것으로 처리하고, 완성된 도형은 더 이상 움직일 수 없도록 만든다.

## 2. 화면 구성

화면을 크게 왼쪽 영역과 오른쪽 영역으로 나누어 구성한다.

### 왼쪽 영역 — 조각 도형 영역

왼쪽에는 다음과 같은 작은 도형들이 배치된다.
- 작은 사각형
- 정삼각형
- 직각삼각형

각 도형의 개수는 랜덤하게 정한다. 각 도형의 위치도 랜덤하게 정한다. 따라서 리셋하거나 새로 시작할 때마다 배치가 달라질 수 있다.

### 오른쪽 영역 — 모양판 영역

오른쪽에는 작은 도형들을 맞춰서 완성해야 하는 모양판을 그린다.

모양판은 총 5종류를 준비한다.

#### 기본 모양판 3종류

수업 자료의 그림에 있는 다음 3종류를 사용한다.

1. 4개의 작은 사각형이 2×2로 모여 하나의 큰 정사각형을 이루는 모양판
2. 삼각형 4개가 중앙을 기준으로 네 방향으로 배치되는 방사형 모양판
3. 직사각형 내부가 하나의 대각선으로 나뉘어 있는 모양판

#### 직접 추가하는 모양판 2종류

기본 모양판 3개 외에 본인이 설정한 새로운 모양판 2개를 추가한다.

따라서 최종적으로 오른쪽에는 기본 모양판 3개 + 직접 만든 모양판 2개 = 총 5개의 모양판이 있어야 한다.

※ 기본 3종류의 정확한 외형은 실습 자료의 그림을 기준으로 구현한다.

## 3. 작은 도형 생성 및 배치

프로그램이 시작되면 왼쪽 영역에 작은 도형들을 랜덤하게 배치한다.

- 사각형 / 정삼각형 / 직각삼각형 중 하나를 사용한다.
- 도형의 개수는 랜덤하다.
- 도형의 위치는 랜덤하다.
- 모양판에 맞춰 배치할 수 있도록 작은 조각 형태로 표시한다.

## 4. 마우스로 도형 선택

왼쪽에 있는 작은 도형을 마우스로 클릭하여 선택한다.

선택한 도형은 마우스 드래그에 따라 이동할 수 있어야 한다.

동작 순서는 다음과 같다.
1. 작은 도형 위에서 마우스 버튼을 누른다.
2. 해당 도형을 선택한다.
3. 마우스를 이동한다.
4. 선택된 도형이 마우스를 따라 이동한다.
5. 마우스 버튼을 놓으면 드래그가 끝난다.

## 5. 도형을 모양판에 맞추기

선택한 작은 도형을 마우스로 드래그하여 오른쪽 모양판으로 가져간다.

단순히 오른쪽 영역에 가져가는 것이 아니라 모양판을 구성하는 올바른 위치에 조각을 맞춰야 한다.

## 6. 모양 완성

하나의 모양판을 구성하는 도형들이 모두 해당 모양판 위에 올라가면 그 모양은 완성된 것으로 처리한다.

완성된 도형은 이후 더 이상 움직일 수 없어야 한다.

즉,
- 아직 완성되지 않은 조각 → 계속 선택 및 드래그 가능
- 필요한 조각이 모두 올라감 → 모양 완성
- 완성된 도형 → 이동 불가능

모양판이 완성되었는지 판단하는 기준은 프로그램에서 구현한다.

## 7. 모양판과 조각의 관계

프로그램은 어떤 작은 도형이 어느 모양판을 구성하는 조각인지 구분할 수 있어야 한다.

예를 들어 기본 모양판에서는 사각형 조각은 2×2 사각형 모양을 구성하고, 삼각형 조각은 4개 삼각형 모양을 구성하며, 직각삼각형 조각은 대각선으로 나뉜 직사각형 모양을 구성한다.

추가로 만든 2개의 모양판 역시 그 모양을 구성하는 작은 도형들을 이용할 수 있도록 설계한다.

## 8. r — 리셋

키보드에서 r을 누르면 리셋하고 새로 시작한다.

리셋 후에는 기존에 배치되어 있던 도형과 완성 상태 등을 초기화하고 다시 시작해야 한다.

## 9. q — 종료

키보드에서 q를 누르면 프로그램을 종료한다.

## 10. 키보드 명령어

| 키 | 동작 |
|---|---|
| r | 리셋하고 새로 시작 |
| q | 프로그램 종료 |

## 11. 최종 체크리스트

- 왼쪽에 작은 사각형, 정삼각형, 직각삼각형 생성
- 작은 도형의 개수를 랜덤하게 결정
- 작은 도형의 위치를 랜덤하게 결정
- 오른쪽에 기본 모양판 3종류 배치
- 본인이 만든 모양판 2종류 추가
- 마우스로 작은 도형 선택
- 선택한 도형을 마우스로 드래그하여 이동
- 도형을 모양판의 올바른 위치에 맞춤
- 모양판에 필요한 도형이 모두 올라갔는지 판단
- 완성된 도형은 더 이상 움직이지 않도록 처리
- r로 전체 리셋
- q로 프로그램 종료

## 12. 문제에서 별도로 정해지지 않은 부분

실습 자료에서는 다음 세부사항의 구체적인 수치나 구현 방법을 지정하지 않는다.
- 랜덤 도형의 정확한 개수 범위
- 랜덤 위치의 정확한 범위
- 조각의 정확한 크기
- 직접 추가하는 모양판 2개의 구체적인 형태
- 모양판에 정확히 맞았다고 판단하는 내부 판정 방법
- 완성된 도형을 화면에 어떻게 표시할지에 대한 별도 효과

따라서 위 항목은 구현자가 결정하되, 실습에서 명시한 전체 동작은 만족해야 한다.
