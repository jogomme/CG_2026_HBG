# Practice 13 — 키보드 명령으로 3차원 객체의 면 그리기

자료 근거: 「지엘3 좌표계 변환 (실습 131415).pdf」 실습 13 슬라이드. 원문 요구와 구현을 위해 추론한 내용을 구분한다.

## 1. 과제 텍스트 전문 추출 (OCR)

**실습 13**
- 3차원 객체, 육면체 또는 사각뿔의 면을 명령어에 따라 그리기
- 화면 중앙에 화면 좌표계 (x축, y축, z축)을 그린다. 은면제거를 한다.
- 모든 객체들은 약간 기울어지게 그린다.
  - 객체는 x축으로 30도, y축으로 30도 회전해 있다. (각도는 변경 가능)
- 키보드 명령어: 도형을 구성하는 각 면을 그린다. 각 면마다 색상을 정해 해당 색상으로 그린다.
  - 1/2/3/4/5/6: 육면체의 각 면을 그린다.
  - 7/8/9/0 : 사각뿔의 삼각형 면을 그린다.
  - c: 육면체에서 랜덤한 2개의 면을 그린다.
  - t: 사각뿔에서 바닥과 랜덤한 1개의 옆면을 그린다.
  - 좌표계는 [-1.0, 1.0]이고, 크기는 원하는 크기로 설정

## 2. 그래픽스 기본 환경 분석

### 환경
과제 제목과 내용상 OpenGL 기반 3D 그래픽스 실습으로 해석한다. 창/입력 라이브러리는 원문에 적혀 있지 않으므로 기존 프로젝트 설정을 유지한다. 은면 제거를 위해 깊이 버퍼와 깊이 테스트가 필요하다. 셰이더 사용 여부는 원문에서 확인할 수 없다.

### 창과 좌표계
창 크기, 배경색은 지정되지 않았다. 화면 중앙에 원점을 두고 x/y/z축을 그린다. 객체는 x축 30도, y축 30도 기울어진 상태로 시작한다. 3D 정점은 x, y, z를 갖는다. 원문에 제시된 좌표 범위는 [-1.0, 1.0]이며, 실제 화면 배치는 카메라와 투영 설정에 따라 달라진다.

### 객체와 색상
육면체는 6개 사각형 면, 사각뿔은 바닥 사각형 1개와 삼각형 옆면 4개로 구성한다. 면마다 고정 색상을 지정한다. 배경 RGB와 정확한 면 색상은 명시되지 않았다. 좌표축 색은 면 색과 구별되도록 정한다.

## 3. 키보드 상호작용 및 상태

| 키 | 동작 |
|---|---|
| 1~6 | 육면체의 각 면을 선택해 표시 |
| 7~0 | 사각뿔의 삼각형 옆면을 선택해 표시 |
| c | 육면체의 6개 면 중 서로 다른 2개를 무작위 선택 |
| t | 사각뿔의 바닥과 옆면 4개 중 무작위 옆면 1개를 표시 |

원문은 숫자 키가 구체적으로 어느 방향의 면인지 지정하지 않는다. 코드에서 면 인덱스와 키 매핑을 정하고 기록한다. 새 명령이 이전 선택을 교체할지 누적할지도 원문은 정하지 않는다. 기본 구현은 해당 도형의 표시 선택을 교체하도록 한다.

필요한 상태는 현재 도형 종류, 육면체 면 표시 여부 6개, 사각뿔 바닥/옆면 표시 여부 5개, 깊이 테스트 상태, 초기 회전각, 랜덤 선택된 면 인덱스다. c와 t의 난수 선택은 키 입력 때 한 번만 수행한다. 렌더링 루프 안에서 매 프레임 난수를 선택하면 면이 깜박인다.

은면 제거는 깊이 테스트를 활성화하고 프레임마다 색상 버퍼와 깊이 버퍼를 지워 구현한다. 실습 13에는 토글 키가 없으므로 기본 상태에서 적용한다.

## 4. 단계별 코딩 구현 계획

1. 기존 창 생성, OpenGL 초기화, 렌더 루프를 유지하고 화면 지우기/그리기/버퍼 교환이 되는지 확인한다.
2. 깊이 테스트를 활성화하고 매 프레임 깊이 버퍼를 초기화한다.
3. 화면 중앙 원점에서 x/y/z축을 서로 다른 색으로 그린다.
4. 육면체의 8개 꼭짓점과 6개 면의 정점 목록을 정의하고 면마다 색상을 지정한다.
5. 사각뿔의 바닥 꼭짓점 4개와 꼭짓점 1개를 정의하고 바닥 및 옆면 4개를 만든다.
6. 객체 전체를 그리는 코드와 면 하나를 그리는 코드를 분리한다.
7. 객체에 x축 30도, y축 30도 회전을 적용한다. 회전 순서를 일관되게 유지한다.
8. 1~6을 육면체 면 선택, 7~0을 사각뿔 옆면 선택에 연결한다.
9. c는 육면체에서 중복 없는 면 2개, t는 바닥과 랜덤 옆면 1개를 선택하게 한다.
10. 랜덤 선택이 키 입력 때만 바뀌는지, 깊이 테스트가 앞뒤 면을 올바르게 처리하는지 확인한다.

## 5. 테스트 체크리스트

- [ ] 화면 중앙에 좌표축이 표시된다.
- [ ] 객체가 x/y축 기준 30도 기울어져 있다.
- [ ] 1~6은 육면체의 각 면을 선택한다.
- [ ] 7~0은 사각뿔 삼각형 옆면을 선택한다.
- [ ] c는 서로 다른 육면체 면 2개를 표시한다.
- [ ] t는 사각뿔 바닥과 옆면 1개를 표시한다.
- [ ] 각 면의 색상이 유지된다.
- [ ] 깊이 테스트가 면의 앞뒤 관계를 올바르게 처리한다.

## 6. 오류 해결과 미확정 사항

면이 안 보이면 키-면 인덱스 매핑을 확인한다. 뒤쪽 면이 앞에 보이면 깊이 테스트/깊이 버퍼 초기화를 확인한다. 면이 사라지면 면 컬링을 사용하는지와 정점 순서를 확인한다. 랜덤 면이 계속 바뀌면 난수 선택을 렌더링 루프 밖으로 옮긴다.

창 크기, 배경 RGB, 정확한 정점 좌표, 투영 방식, 면 색상표, 숫자 키별 방향 면 매핑은 원문에서 지정하지 않는다. 임의로 정한 사항은 필수 조건과 구분해 주석으로 남긴다.
