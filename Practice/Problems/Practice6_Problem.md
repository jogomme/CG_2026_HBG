# OpenGL 실습 6 — 사각형 분할

## 초기 상태
- 사각형 5~10개.
- 위치/색상은 임의.

## 클릭
- 사각형을 클릭하면 해당 사각형을 4개로 분할한다.
- 분할된 네 사각형은 원래 영역을 기준으로 배치한다.
- 분할 후 각 사각형을 독립적으로 관리한다.

## 애니메이션
- 위치 애니메이션.
- 색상 애니메이션.
- 크기 애니메이션.
- 사각형이 작아지면서 사라지는 효과.
- 여러 이동 방식을 구현한다.

## 상태
- 배열/개수
- 선택 인덱스
- 위치
- 크기
- 색상
- 이동 방향/속도
- 크기 변화 방향/속도
- 애니메이션 상태
- 삭제/사라짐 상태

## 구현 순서
1. 초기 사각형 생성.
2. 클릭한 사각형 찾기.
3. 기존 사각형을 네 영역으로 나누기.
4. 네 사각형의 상태 생성.
5. 위치/색상/크기 애니메이션 갱신.
6. 충분히 작아진 사각형 제거 또는 사라짐 처리.

## 원문에서 정하지 않은 부분
각 이동 모드의 정확한 경로, 속도, 크기 감소량, 색상 변화 방식은 과제의 동작을 만족하도록 구현한다.
