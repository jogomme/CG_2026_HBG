# OpenGL 실습 8 — 사분면 삼각형

## 화면
- 화면을 네 사분면으로 나눈다.
- 각 영역에 삼각형을 배치한다.
- 위치/크기/색상을 관리한다.

## 마우스
- 마우스로 삼각형 선택.
- 선택된 삼각형 이동/조작.
- 마우스 좌표를 OpenGL 좌표로 변환.
- 선택되지 않은 삼각형은 선택된 삼각형의 조작 영향을 받지 않는다.

## 키보드/애니메이션
- 과제에서 지정한 키로 크기 변경.
- 확대/축소.
- 과제에서 지정한 키로 색상 변경.
- 지정된 이동 모드를 키로 선택.
- 선택한 모드에 따라 매 프레임 위치 갱신.
- 모드 변경 시 현재 위치에서 이어서 이동.

## 상태
- 삼각형 배열
- 선택 인덱스
- 드래그 상태
- 위치
- 크기
- 색상
- 이동 모드
- 속도/방향

## 구현 순서
1. 네 사분면과 삼각형 데이터 준비.
2. 삼각형 선택 판정.
3. 선택된 삼각형 이동.
4. 크기/색상 키 처리.
5. 이동 모드 처리.
6. 매 프레임 위치 갱신.
