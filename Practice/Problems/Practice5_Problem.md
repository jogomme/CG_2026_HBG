# OpenGL 실습 5

## 문제
20~40개의 작은 사각형을 화면에 생성하고 마우스 지우개와 충돌 효과를 구현한다.

## 조건
- 작은 사각형을 20~40개 임의의 위치에 생성한다.
- 사각형은 임의의 색상으로 설정한다.
- 마우스를 지우개처럼 사용한다.
- 지우개와 사각형이 충돌했을 때 사각형을 삭제하거나 크기 또는 색상을 변화시킨다.
- 마우스를 놓으면 원래 상태로 돌아오도록 한다.
- 마우스 오른쪽 버튼으로 사각형을 추가할 수 있다.
- 추가할 수 있는 사각형은 최대 10개로 제한한다.
- `r` 키를 누르면 초기 상태로 되돌린다.
