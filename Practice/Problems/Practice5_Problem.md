# OpenGL 실습 5 — 사각형 지우개

## 초기 상태
- 작은 사각형 20~40개.
- 위치/색상은 임의.
- 마우스를 지우개처럼 사용.

## 마우스/충돌
- 마우스 위치를 기준으로 지우개 영역을 만든다.
- 지우개와 사각형의 충돌을 검사한다.
- 충돌 시 요구된 효과를 적용한다.
- 효과에는 삭제, 크기 변화, 색상 변화가 포함된다.
- 마우스를 놓으면 변경된 사각형은 원래 상태로 복구한다.
- 복구에 필요한 원래 상태를 저장한다.

## 오른쪽 클릭
- 오른쪽 버튼으로 사각형 추가.
- 새 사각형은 임의 위치/색상.
- 추가 가능 수는 최대 10개.
- 한도에 도달하면 추가하지 않는다.

## r
- 초기 상태로 리셋.
- 충돌/지우개 상태도 초기화.

## 처리 순서
1. 마우스 위치를 얻는다.
2. 지우개 영역을 계산한다.
3. 각 사각형과 충돌 검사.
4. 충돌한 사각형에 효과 적용.
5. 마우스를 놓으면 원래 상태 복구.

## 구현 상태
- 사각형 배열/개수
- 원래 위치/크기/색상
- 현재 상태
- 지우개 활성화 상태
- 마우스 버튼 상태
- 충돌 상태
- 오른쪽 클릭 추가 개수

## 원문에서 정하지 않은 부분
지우개의 정확한 크기, 충돌 판정 방식, 충돌 효과의 구체적 수치/종류별 적용 방식은 구현 단계에서 과제 조건에 맞게 결정한다.
