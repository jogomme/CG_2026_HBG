# OpenGL 실습 9 — 삼각형 애니메이션

## 기본
- 이등변 삼각형 여러 개.
- 각 삼각형이 서로 다른 방향과 속도로 이동.
- 위치/방향/속도를 개별 관리.

## 1 — Bounce
- 이동.
- 화면 가장자리에 부딪히면 방향 반전.
- 삼각형 전체가 화면 안에 남도록 경계 계산.

## 2 — Horizontal Zigzag
- 좌우 방향으로 이동.
- 좌우 경계에서 방향 반전.
- 수평 지그재그 경로.

## 3 — Vertical Pointed Zigzag
- 상하 방향을 중심으로 이동.
- 위/아래 경계에서 방향 반전.
- 뾰족한 지그재그 형태.

## 4 — Spiral
- 원형/나선형 경로.
- 시간에 따라 각도와 반지름 변화.
- 나선 형태로 위치 계산.

## 공통
- 매 프레임 위치 갱신.
- 삼각형별 속도 차이 유지.
- 방향 독립 관리.
- 화면 밖으로 나가지 않게 처리.

## 키 상호작용
- 1~4는 이동 모드 변경.
- 모드를 바꿔도 현재 위치를 유지하고 새 방식으로 이동.
- 별도의 정지/리셋 키가 원문에 있다면 그 조건에 맞게 처리.

## 상태
- 삼각형 배열
- 중심 위치
- 정점
- 속도/방향
- 현재 모드
- 스파이럴 각도/반지름
- 애니메이션 시간

## 원문에서 정하지 않은 부분
각 모드의 정확한 속도값, 스파이럴 중심/반지름 범위, 키 입력 시 모드 전환 방식의 세부 구현은 과제 조건을 만족하도록 결정한다.
