# Practice 17 — 모델링 변환: 두 3D 객체 조작하기

자료 근거: 「지엘3 좌표계 변환 (실습 1617).pdf」의 실습 17 슬라이드.

## 1. 과제 텍스트 전문 추출 (OCR)

**실습 17**
- 모델링 변환하기
- 화면의 중앙에 좌표계 (x, y, z축)을 그린다. 좌표계와 3차원 객체들은 모두 x, y축에 대해 30도 기울어져 있다.
- 화면의 좌, 우에 3차원 객체를 그리고, 키보드 명령으로 객체 변환 하기
  - 예) 우: 육면체, 좌: 원뿔 (또는, 구)

**키보드 명령**
- 1을 누르면 좌측의 객체만, 2를 누르면 우측의 객체만, 3을 누르면 두 객체 모두에 적용한다.
  - x/X: 객체의 x축에 대하여 각각 양/음 방향으로 회전하기 (자전)
  - y/Y: 객체의 y축에 대하여 각각 양/음 방향으로 회전하기 (자전)
  - r/R: 중앙의 y축에 대하여 양/음 방향으로 회전하기 (공전)
  - a/A: 도형이 제자리에서 확대/축소
  - b/B: 도형이 원점에 대해서 확대/축소 (위치도 바뀐다.)
  - d/D: 도형이 x축에서 좌/우로 이동
  - e/E: 도형이 y축에서 위/아래로 이동
- 아래의 변환 애니메이션은 두 도형에 같이 적용된다.
  - t: 두 도형이 원점을 통과하며 상대방의 자리로 이동하는 애니메이션
  - u: 두 도형이 한 개는 위로, 다른 도형은 아래로 이동하면서 상대방의 자리로 이동하는 애니메이션
  - v: 두 도형이 한 개는 확대, 다른 한 개는 축소되며 자전과 공전하기
- c: 두 도형을 다른 도형으로 바꾼다.
- s: 초기화 하기
- q: 프로그램 종료

## 2. 그래픽스 기본 환경 분석

OpenGL 기반 3D 모델링 변환 실습으로 해석한다. 창 크기, 배경색, 도형 크기/색상, 투영 방식, 애니메이션 속도는 원문에 없다. 화면 중앙에 좌표축을 두고 객체 두 개를 좌우에 배치한다. 예시는 왼쪽 원뿔 또는 구, 오른쪽 육면체지만 필수 조합이라고 단정할 수 없다.

좌표축과 객체는 x/y축 기준 30도 기울어진다. 이 기본 기울기와 사용자가 실행하는 객체별 변환은 구분한다. 좌표축은 객체가 이동/회전해도 움직이지 않도록 별도 렌더링한다.

## 3. 키보드 상호작용 및 상태

### 대상 선택
- 1: 왼쪽 객체만 변환
- 2: 오른쪽 객체만 변환
- 3: 두 객체 모두 변환

이 선택은 x/X, y/Y, r/R, a/A, b/B, d/D, e/E에 적용한다. t/u/v는 원문에서 두 도형에 같이 적용된다고 했으므로 대상 선택과 관계없이 양쪽 객체를 모두 갱신한다.

### 객체 변환 키
| 키 | 의미 | 변환 개념 |
|---|---|---|
| x/X | x축 양/음 방향 자전 | 위치를 유지하며 방향 회전 |
| y/Y | y축 양/음 방향 자전 | 위치를 유지하며 방향 회전 |
| r/R | 중앙 y축 양/음 방향 공전 | 원점 주위로 객체 위치가 회전 |
| a/A | 제자리 확대/축소 | 중심 위치를 유지하며 크기 변경 |
| b/B | 원점 기준 확대/축소 | 원점으로부터의 위치와 크기가 함께 변경 |
| d/D | x축 좌/우 이동 | x 위치 변경 |
| e/E | y축 위/아래 이동 | y 위치 변경 |

원문은 x/X, y/Y, r/R의 방향을 명시한다. a/A와 b/B의 확대/축소 방향, d/D와 e/E의 구체적인 방향 매핑은 정확히 지정하지 않으므로 구현 규칙을 정하고 기록한다.

### 복합 애니메이션
- t: 두 객체가 원점을 통과하면서 서로 상대방의 자리로 이동한다.
- u: 한 객체는 위로, 다른 객체는 아래로 이동하면서 상대방 자리로 간다.
- v: 한 객체는 확대, 다른 객체는 축소되며 자전과 공전을 함께 한다.

t/u/v는 두 객체 모두에 적용된다. 동시 실행 규칙은 원문에 없으므로 첫 구현에서는 이 세 기능 중 하나를 시작하면 나머지 복합 애니메이션은 중지하도록 할 수 있다.

### 기타
- c: 두 객체를 다른 도형으로 바꾼다. 도형 종류와 순서는 정해져 있지 않으므로 예를 들어 Cube/Cone/Sphere 순환으로 구현하고 기록한다.
- s: 초기화한다. 객체 위치, 회전, 스케일, 대상 모드, 애니메이션 상태를 초기값으로 복원하는 것이 합리적이다.
- q: 프로그램 종료.

필요한 상태는 대상 모드, 각 객체의 종류/위치/회전/스케일, t/u/v 활성 상태와 진행값, 애니메이션 속도다.

## 4. 자전·공전·스케일 차이

**자전:** 객체의 위치는 유지하면서 자기 축 기준으로 회전한다. x/X와 y/Y가 이에 해당한다.

**공전:** 객체가 중앙 y축 주위를 돌며 위치가 변한다. r/R에서는 객체의 방향만 회전시키는 것이 아니라 원점 기준 위치 벡터도 회전시켜야 한다.

**제자리 스케일:** a/A는 객체 중심을 유지하면서 크기를 바꾼다.

**원점 기준 스케일:** b/B는 원점에서 객체까지의 위치도 변한다. 원점에서 멀리 있는 객체를 확대하면 더 멀어지면서 커지고, 축소하면 원점 쪽으로 가까워지면서 작아진다.

변환 순서와 pivot을 잘못 잡으면 자전이 공전처럼 보이거나 a와 b가 같은 동작처럼 보인다. 행렬 적용 순서는 사용하는 수학 라이브러리의 convention을 확인한다.

## 5. 단계별 코딩 구현 계획

1. 왼쪽 원뿔/구와 오른쪽 육면체 등 두 3D 객체를 준비한다.
2. 중앙 좌표축을 그리고 객체의 변환과 분리한다.
3. 좌우 객체 각각 위치, 회전각, 스케일, 종류를 저장한다.
4. 1/2/3으로 대상 모드를 설정한다.
5. x/X와 y/Y는 선택된 객체의 회전만 바꾸고 위치를 유지한다.
6. r/R는 중앙 y축 기준으로 위치 벡터를 회전시켜 공전시킨다.
7. a/A는 중심을 유지한 스케일, b/B는 원점 기준 위치와 크기 변화를 구현한다.
8. d/D는 x 위치, e/E는 y 위치를 변경한다.
9. t에서는 두 객체의 시작 위치를 저장하고 원점을 통과해 서로의 자리로 가는 경로를 만든다. 단순 직선 보간이 원점을 지나지 않는 배치라면 구간별 경로를 사용한다.
10. u에서는 한 객체는 위쪽, 다른 객체는 아래쪽 경로로 서로의 자리까지 이동시킨다.
11. v에서는 한 객체는 확대, 다른 객체는 축소하면서 두 객체에 자전과 공전을 함께 적용한다.
12. c는 두 객체의 종류를 다른 도형으로 교체한다.
13. s는 위치/회전/스케일/대상 모드/애니메이션 상태를 초기화한다.
14. q는 프로그램을 종료한다.
15. 애니메이션은 프레임당 고정량보다 delta time을 이용해 갱신한다.

## 7. 오류 해결 및 미확정 사항

자전 중 위치가 변하면 원점 기준 회전을 적용했는지 확인한다. 공전 중 위치가 그대로라면 위치 벡터를 회전시키는지 확인한다. a와 b가 같으면 pivot/행렬 순서를 분리한다. 1/2 선택이 무시되면 선택 대상에 따라 객체별 상태를 갱신하는지 확인한다. t/u/v가 한 객체만 움직이면 두 객체를 모두 갱신하는지 확인한다. 리셋 후에도 움직이면 애니메이션 활성 상태와 진행값도 초기화한다.

창 크기, 배경색, 객체 종류, 색상, 이동 단위, 회전 속도, a/A와 b/B의 방향 매핑, d/D와 e/E의 방향, 복합 애니메이션 시간/반복 방식, c의 도형 순서는 원문에서 정하지 않는다.
