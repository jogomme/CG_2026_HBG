# OpenGL 실습 5

## 화면 지우기

### 실습 목표

윈도우를 띄우고 여러 개의 작은 사각형을 생성한 뒤, 마우스를 이용하여 지우개처럼 사각형을 지우고 충돌에 따라 지우개의 상태를 변화시킨다.

---

## 구현 내용

### 1. 사각형 생성

* 화면에 **같은 크기의 작은 사각형 20~40개**를 랜덤한 위치에 생성한다.
* 각 사각형은 랜덤한 색상을 가진다.

### 2. 왼쪽 마우스 버튼

* 왼쪽 마우스 버튼을 누르면 마우스 위치를 중심으로 **화면의 작은 사각형의 2배 크기의 검정색 지우개 사각형**이 나타난다.
* 마우스를 누른 채로 이동하면 지우개 사각형도 마우스를 따라 이동한다.

### 3. 지우개와 사각형 충돌

* 지우개 사각형과 부딪친 작은 사각형은 사라진다.
* 사각형이 하나 사라질 때마다 지우개 사각형의 크기가 커진다.
* 지우개 사각형의 색상은 부딪힌 사각형의 색상으로 변경된다.
* 지우개와 충돌한 사각형은 마우스를 누르고 있는 동안 사라진 상태를 유지한다.

### 4. 왼쪽 마우스 버튼 Release

* 왼쪽 마우스 버튼을 떼면 지우개 사각형이 사라진다.
* 지우개에 의해 사라졌던 사각형들은 처음 생성되었던 원래 위치와 상태로 다시 나타난다.
* 다음에 다시 마우스를 누르면 **검정색의 기존 지우개 크기**로 지우개가 생성된다.

### 5. 오른쪽 마우스 버튼

* 오른쪽 마우스 버튼을 누른 위치에 새로운 사각형을 생성한다.
* 새로운 사각형이 생성되면 지우개 사각형의 크기가 줄어든다.
* 새롭게 추가할 수 있는 사각형은 최대 **10개**이다.

### 6. 키보드 입력

| 키 | 기능 |
| --- | --- |
| `R` | 기존 사각형들을 삭제하고 초기 상태로 다시 시작한다. |
| `Q` | 프로그램을 종료한다. |

---

## 입력 방식

### Callback

* 왼쪽 마우스 버튼의 Press / Release 처리
* 오른쪽 마우스 버튼의 Press 처리
* `R`, `Q` 키 입력 처리

### Polling

* 왼쪽 마우스 버튼을 누르고 있는 동안 지우개 사각형의 위치를 확인한다.
* 마우스가 이동하는 동안 지우개와 사각형의 충돌을 계속 확인한다.

---

## 주요 조건

* 작은 사각형은 **20~40개** 생성한다.
* 모든 작은 사각형은 같은 크기로 생성한다.
* 작은 사각형의 위치와 색상은 랜덤으로 설정한다.
* 지우개 사각형은 작은 사각형의 2배 크기로 시작한다.
* 지우개 사각형은 처음에는 검정색이다.
* 지우개와 충돌한 사각형은 사라진다.
* 사각형이 사라질 때마다 지우개 크기가 커진다.
* 충돌한 사각형의 색상으로 지우개 색상이 변경된다.
* 마우스 Release 시 지우개가 사라지고 사라진 사각형이 복구된다.
* 다시 마우스를 누르면 지우개는 검정색과 기존 크기로 시작한다.
* 오른쪽 마우스 클릭으로 사각형을 추가할 수 있다.
* 추가 가능한 사각형은 최대 **10개**이다.
