# OpenGL 실습 5

## 사각형 충돌 및 지우기

### 실습 목표

여러 개의 사각형을 화면에 생성하고, 마우스를 이용하여 사각형을 지우거나 충돌시켜 사각형의 상태를 변화시키는 기능을 구현한다.

---

## 구현 내용

### 1. 사각형 생성

* 화면에 **20~40개의 작은 사각형**을 랜덤하게 생성한다.
* 각 사각형은 랜덤한 위치와 랜덤한 색상을 가진다.

### 2. 마우스 입력

마우스를 이용하여 사각형을 지울 수 있다.

#### 왼쪽 마우스 버튼

* 마우스를 클릭하여 사각형을 지운다.
* 지우개처럼 동작하도록 구현한다.

#### 오른쪽 마우스 버튼

* 새로운 사각형을 추가한다.
* 최대 **10개까지** 추가할 수 있다.

---

## 충돌 처리

마우스로 사각형을 지울 때 다른 사각형과 충돌하면 충돌한 사각형에도 변화가 발생한다.

충돌 상황에 따라 사각형의 상태가 변경된다.

* 사각형 삭제
* 사각형 크기 변경
* 사각형 색상 변경

---

## 마우스 버튼을 놓았을 때

마우스 버튼을 놓으면 지우개에 의해 변경된 사각형이 원래 상태로 돌아오도록 구현한다.

즉, 마우스를 누르고 있는 동안에는 충돌 및 삭제가 적용되고, 마우스를 놓으면 원래 상태를 복구한다.

---

## 키보드 입력

| 키   | 기능             |
| --- | -------------- |
| `R` | 사각형을 초기 상태로 리셋 |

---

## 주요 조건

* 작은 사각형 **20~40개**를 랜덤하게 생성
* 마우스 지우개 기능 구현
* 사각형 충돌 처리
* 충돌에 따른 사각형의 삭제 / 크기 변경 / 색상 변경
* 마우스 버튼을 놓으면 변경된 상태 복구
* 오른쪽 마우스 클릭으로 사각형 추가
* 추가 가능한 사각형은 최대 **10개**
* `R` 키를 이용한 초기화

---

## 조작 방법

| 입력             | 동작            |
| -------------- | ------------- |
| 마우스 왼쪽 버튼      | 사각형 지우개       |
| 마우스 오른쪽 버튼     | 사각형 추가        |
| 마우스 버튼 Release | 변경된 사각형 상태 복구 |
| `R`            | 전체 리셋         |
