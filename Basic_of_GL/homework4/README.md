# 실습과제 4

## 과제 내용

- 사각형에 애니메이션 적용하기
- 배경색은 짙은 회색으로 설정
- 사각형은 랜덤한 색으로 그리기
- 마우스를 클릭한 곳을 중심으로 사각형 생성
- 최대 5개의 사각형 생성

## 키보드 입력

- 1: 위치 변화 1
  - 사각형들이 각각 대각선으로 이동
  - 벽에 닿으면 튕겨 다른 방향으로 이동
  - 다시 입력하면 멈춤

- 2: 위치 변화 2
  - 사각형들이 가로 지그재그로 이동
  - 다시 입력하면 멈춤

- 3: 위치 변화 3
  - 모든 사각형들이 윈도우 가장자리를 따라 시계방향으로 이동
  - 다시 입력하면 멈춤

- 4: 크기 변화
  - 사각형의 크기가 커졌다 작아졌다 반복
  - 다시 입력하면 멈춤

- 5: 색상 변화
  - 사각형의 색상이 랜덤하게 변화
  - 다시 입력하면 멈춤

- S: 모든 애니메이션 정지
- M: 원래 그린 위치로 이동
- R: 사각형 삭제 후 다시 마우스 입력 가능
- Q: 프로그램 종료
