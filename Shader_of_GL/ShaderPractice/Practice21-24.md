# 실습 21~24 실행·조작 안내

저장소 전체를 받은 다음 `ShaderPractice.slnx`를 열고 실행할 과제를 시작 프로젝트로 선택한다. `x64`의 Debug 또는 Release로 빌드한다. 다른 컴퓨터에서는 [저장소 README](../../README.md)의 OpenGL 의존성 준비 절차를 먼저 수행한다. 프로젝트는 공통 소스 및 OpenGL 설정을 상대 경로로 참조한다.

## 21번 — 3차원 공 튕기기

| 입력 | 동작 |
|---|---|
| `B` | 공 추가, 최대 다섯 개 |
| `Z` / `Shift+Z` | 방을 z축 양/음 방향으로 이동 |
| `Y` / `Shift+Y` | 방을 y축 기준 시계/반시계 방향으로 회전 |
| 마우스 왼쪽 버튼 드래그 | 육면체 세 개를 z축 기준으로 굴려 바닥을 따라 이동 |
| `O` | 바닥 열기/닫기 |
| `R` | 처음 상태로 복원 |

원근 투영, 깊이 검사와 뒷면 컬링을 사용한다. 방의 앞면은 그리지 않지만 공을 위한 경계는 남긴다. 공 중심은 벽에서 반지름만큼 떨어진 자리에서 반사된다. 바닥을 열면 공과 육면체가 아래로 떨어진다. 닫히면 처음 공 한 개와 바닥 위 육면체가 다시 준비된다.

## 22번 — 탱크 뷰포트 세 개

왼쪽은 원근 투영, 오른쪽 위는 직각 투영 평면도(xz), 오른쪽 아래는 직각 투영 정면도(xy)다. 방향키로 탱크를 움직인다. 실습 19의 조작과 애니메이션도 같은 장면 상태를 사용한다. 장면 상태는 프레임마다 한 번만 갱신하고 같은 탱크를 세 번 그린다. `glScissor`로 각 뷰포트의 배경과 깊이 버퍼를 따로 지운다.

## 23번 — 로봇 무대

| 입력 | 동작 |
|---|---|
| `O` | 반투명 앞문을 위로 올려 열기/닫기 |
| `W/A/S/D` | 앞/왼쪽/뒤/오른쪽으로 걷는 방향 변경 |
| `+/-` | 걷기 속도와 팔·다리 흔들림 크기 조절 |
| `J` | 제자리 점프. 공중에서 방향 키를 누르면 장애물 위로 이동할 수 있음 |
| `X/Z`, 각 키의 Shift 조합 | 카메라 x/z축 양/음 방향 이동 |
| `Y` / `Shift+Y` | 카메라 y축 기준 공전 방향 전환 |
| `I` | 변환 초기화 및 장애물 배치 다시 생성 |

로봇은 벽이나 장애물 옆면에서 반대로 돈다. 발 높이가 장애물 윗면보다 높으면 이동할 수 있고, 내려오는 중 윗면과 만나면 착지한다. 윗면의 끝을 걸어 나가면 바닥으로 떨어진다.

## 24번 — 택배 트럭과 상자 시점

| 입력 | 동작 |
|---|---|
| `1~5` | 해당 상자 적재. 이미 실은 상자는 중복 적재하지 않음 |
| `V` | 3인칭/상자 1인칭 전환. 처음 선택된 상자는 5번 |
| `N` / `Shift+N` | 1인칭에서 다음/이전 번호로 순환 |
| `G` | 트럭 출발/정지. 바닥 끝에 도착하면 정지하고 다음 출발은 반대 방향 |
| `R` | 벨트·트럭·적재·시점 초기화 |

실습 20의 벨트, 번호, 벨트 정지(`B`), 3인칭 줌·시점 조작을 유지한다. 상자 시점은 현재 상자의 위치와 앞 방향을 함께 사용하므로 코너와 트럭에서도 따라간다. 모든 실습은 `Q` 또는 `Esc`로 종료한다.
